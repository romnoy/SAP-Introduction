# לרקוד על עננים — דף נחיתה

## מבנה הקבצים
- `index.html` — כל התוכן והטקסטים של הדף
- `style.css` — הצבעים, הגופנים והעיצוב (הצבעים מרוכזים בראש הקובץ)
- `script.js` — אנימציות עדינות וחלון הגדלה לגלריה
- `assets/` — התמונות

## פרסום ב-GitHub Pages
1. יוצרים מאגר (repository) חדש ב-GitHub.
2. מעלים את כל הקבצים והתיקיות כמו שהם (Add file → Upload files).
3. נכנסים ל-Settings → Pages, בוחרים Branch: `main` ותיקייה `/ (root)` ושומרים.
4. אחרי דקה-שתיים הדף יהיה זמין בכתובת שמופיעה שם.

## עדכונים נפוצים
- **המלצות:** ב-`index.html` מחפשים "המלצה תתווסף בקרוב", מחליפים בטקסט אמיתי ובשם, ומוחקים את המילה `placeholder` מהשורה `class="quote placeholder"`.
- **מספר הוואטסאפ / ההודעה המוכנה:** מחפשים `wa.me/972525280560` — הטקסט שאחרי `?text=` הוא ההודעה שנפתחת אוטומטית.
- **שאלה חדשה:** מעתיקים בלוק `<details>` שלם באזור השאלות.
